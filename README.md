# Instagram Followers Data Analysis

An exploratory data analysis (EDA) project that studies Instagram audience characteristics and user engagement patterns across a dataset of **10,000 user records**.

## Project Overview

This project analyzes audience demographics and content-consumption behaviour to identify patterns that can help creators and brands understand their Instagram followers and make more informed content decisions.

## Analysis Focus

- **Audience demographics:** Explore age, country, and gender distributions.
- **Engagement behaviour:** Examine how users interact with and consume content.
- **Time spent consuming content:** Identify patterns in the time users spend on Instagram content.
- **Audience insights:** Summarize trends that may support content planning and audience strategy.

## Business Use Cases

- Understand the demographic composition of an Instagram audience.
- Identify audience segments that may respond differently to content.
- Use engagement and consumption patterns to guide social media planning.
- Support data-informed decisions for creator and brand marketing strategies.

## Dataset

The analysis uses 10,000 Instagram user records. Refer to the files in this repository for the dataset, column definitions, and analysis implementation.

## How to Explore

1. Clone or download this repository.
2. Review the dataset and analysis files.
3. Open the notebook or script included in the repository using the relevant data-analysis environment.
4. Run the analysis to reproduce the findings.
